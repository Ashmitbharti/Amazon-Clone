# Amazon Clone

A simple Amazon-inspired e-commerce website built using HTML, CSS, and vanilla JavaScript.

## About

I built this project to learn modern JavaScript by recreating the core functionality of an e-commerce website. The application allows users to browse products, manage a shopping cart, choose delivery options, place orders, and view previous orders.

This project helped me learn about:
- ES6 modules
- Asynchronous JavaScript (`fetch`, `async/await`)
- DOM manipulation
- Local Storage
- Writing unit tests with Jasmine

## Features

- Browse products
- Add and remove items from the cart
- Update delivery options
- Dynamic checkout page
- Order history
- Order tracking
- Cart persistence using Local Storage

## Built With

- HTML
- CSS
- JavaScript
- Fetch API
- Local Storage
- Jasmine

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Ashmitbharti/Amazon-Clone.git
```

Open `amazon.html` using Live Server or any local web server.

You can navigate to the checkout page by simply clicking the cart option or by opening `checkout.html` using Live Server.
